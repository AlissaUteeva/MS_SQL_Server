# Конспект 04.09

База данных - это организованное электронное хранилище структурированной информации
SQL сервер - это система управления реляционными базами данных

## Microsoft SQL Server
это корпоративная реляционная СУБД, построенная по клиент-серверной архитектуре

1.      Клиент отправляет запрос на языке Т-SQL серверной машине.
2.      Сервер принимает обращение с требованием выполнить определенное действие и выполняет поставленную задачу.
3.      Программно-аппаратный комплекс отправляет клиенту результат выполненной работы, обработанного запроса.


## Как создать Базу данных в SQL manager studio
### Создание бд
1. Запустить SQL Server Manager от имени администратора
2. Соединиться с сервером
3. Пкм по папке Базы данных -> Создать базу данных
4. Создаем базу данных
### Создание таблиц
1.1 Пкм по папке Таблицы в созданной бд Создать -> Таблицы...
или
1.2 Создать запрос
```
use [имя бд] 
go
create table [название таблицы] (
....
);
```
### В состав бд входят:
- Таблицы
- Представления
- Хранимые процедуры
- BLOB-поля
- Иные данные

### Системные базы данных
**master** - главная база данных сервера, хранит все логины пользователей, их роли, настройки, имена и информацию о базах данных. В ней ничего не пишем
**model** - шаблон на основе которых создаются другие базы данных
**msdb** - хранит информацию о работе, выполняемой таким компонентом как планировщик SQL + информацию о бекапах без данных
**tempbd** - используется как хранилище для временных объектов, пересоздается при каждом запуске

## Как заполнить таблицу
1.2 Пкм по таблице -> Изменить первые 200 строк
или
1.2 Создать запрос
```
CREATE TABLE названиетаблицы
(название_столбца1 тип_данных атрибуты_столбца1,
.......
атрибуты_таблицы)
```
Данные столбцов таблицы:
**Column name** - имя столбца
**Data type** - тип данных столбца
**Allow Nulls** - может ли отсутствовать значение у столбца

## Прикрепление базы данных
Файл базы данных представляет файл с расширением mdf и этот файл можно переносить, но если его просто скопировать, то база данных, к в которой он был создан просто так не появится
Для этого нужно выполнить прикрепление базы данных к серверу
```
CREATE DATABASE названиеБД
ON PRIMARY(FILENAME='путь к файлу")
FOR ATTACH;
```

## Удаление базы данных 
Для удаления базы данных применяется команда DROP DATABASE
```
DROP DATABASE databasename1 [, databasename2]...
```
