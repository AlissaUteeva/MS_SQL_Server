# Анализ
- **Что изучалось:** автоматизация отслеживания изменений в таблицах с помощью триггеров после вставки данных AFTER INSERT
- **В чем заключается задание:** создание триггеров tr_STUDENT_AfterInsert и trg_STUDENT_Insert для автоматического переноса информации о добавленных студентах в специализированные таблицы логов аудина StudentAuditLog и StudentLog
- **Какие навыки закрепляет:** разработка DML-триггеров, работа с виртуальными контекстными таблицами сервера inserted для извлечения новых записей и автоматизация ведения журналов истории операций
