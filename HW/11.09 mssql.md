# Анализ
- **Что изучалось:** разработка программируемых объектов базы данных скалярных функций и хранимых процедур для обработки данных и вычислений
- **В чем заключается задание:** реализация скалярной функции для демонстрации работы встроенных инструментов и хранимой процедуры dbo.sp_CalculateStudentDifference для расчета разницы между поступившими и выпустившимися студентами
- **Какие навыки закрепляет:** написание DDL-команд CREATE FUNCTION, CREATE PROCEDURE, использование входных параметров и локальных переменных, приведение типов через CAST и вычисление бизнес-метрик на T-SQL
