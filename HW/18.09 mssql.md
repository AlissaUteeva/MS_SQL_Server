# Анализ
- **Что изучалось:** использование виртуальных таблиц для инкапсуляции и фильтрации запросов
- **В чем заключается задание:** создание обычного представления с условием WHERE и модифицируемого представления для работы с ограниченным набором колонок таблицы студентов
- **Какие навыки закрепляет:** написание команд CREATE VIEW, ограничение доступа к данным через вертикальные и горизонтальные срезы таблиц
